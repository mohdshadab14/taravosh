# Taravosh

> A backend engineering project built to learn, experiment, and evolve from Core Java to Spring Boot and eventually AWS.

## About

**Taravosh** (تراوش) is a Persian word associated with the idea of *flowing, emerging, or emanating*.

The project represents the gradual flow of ideas and learning into a real-world software system.

This repository will evolve incrementally as new backend engineering concepts are learned and implemented.

## Learning Goals

The primary goals of Taravosh are to gain hands-on experience with:

- Core Java
- Object-Oriented Programming
- Collections and Generics
- Java Streams and Functional Programming
- Exception Handling
- Multithreading and Concurrency
- JVM fundamentals
- Clean Code and SOLID principles
- Design Patterns
- Spring Framework
- Spring Boot
- REST API development
- Spring Security
- JWT Authentication & Authorization
- ORM using JPA/Hibernate
- JDBC and native SQL
- PostgreSQL
- Database transactions and optimization
- File Upload and Download
- Caching
- Asynchronous processing
- Scheduled jobs
- API documentation
- Unit and Integration Testing
- Docker
- GitHub Actions
- CI/CD
- Cloud architecture
- AWS Solutions Architecture
