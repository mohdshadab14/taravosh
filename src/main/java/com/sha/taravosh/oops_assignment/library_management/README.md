# Assignment 03: Library Management System

## Objective
Build a library system using an abstract class, an interface, inheritance, `ArrayList`, and `HashMap`.

## Requirements
1. Create an abstract `LibraryItem` class.
2. Create `Book`, `Magazine`, and `ResearchPaper`.
3. Create a `Borrowable` interface.
4. `Book` and `Magazine` should implement `Borrowable`.
5. Store all items in `HashMap<Integer, LibraryItem>`.
6. Store borrowed items in `ArrayList<LibraryItem>`.
7. Prevent borrowing an unavailable item.
8. Implement borrow, return, search, display, and removal operations.

## Suggested Package
`com.example.library`
